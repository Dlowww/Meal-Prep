# Batch Prep

A personal meal-prep and grocery-list web app for batch cooking lunch and dinner.

- Runs entirely in the browser; all data is saved on your phone (localStorage).
- No build step: plain HTML, CSS and JavaScript.
- Run the tests with `npm test` (needs Node.js 18+).

## Stages
1. Targets screen and meal math (breakfast + after-dinner eaten fresh; lunch + dinner batch-cooked) ✅
2. Recipe search (Spoonacular): ranked options, portion scaling, macro tuning (½×–2× on main ingredients, plus an optional add-on), batch ingredients ✅
3. Grocery list: combined lunch + dinner totals with per-meal split, store sections, shopping units, saved ticks, checkout-total pricing from built-in US prices ✅
4. Favorites: heart to save full recipes, reuse as lunch or dinner without searching ✅
5. Home-screen app (PWA: icon, full screen, works offline) and hosting on GitHub Pages ✅

Live at https://dlowww.github.io/Meal-Prep/
